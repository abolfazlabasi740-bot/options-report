- وضعیت: هنوز برای این پایپ‌لاین انجام نشده.

### مرحله 1 — تکمیل دفتر شواهد بورس‌ویو (P0)
- کار: دسته‌بندی قابلیت‌ها و فیلترهای قابل مشاهده در سایت، آموزش‌ها و کانال رسمی؛ فرمول دقیق فقط در صورت انتشار ثبت شود.
- خروجی: شناسه، URL، توضیح، فرمول، وضعیت دسترسی ماشینی و محدودیت.
- معیار پایان: هر ادعا شاهد داشته باشد و موارد نامعلوم صریحاً نامشخص بمانند.

### مرحله 2 — ممیزی TSETMC در کد موجود (P0)

- خروجی: ماتریس فیلد خام، endpoint، ماژول فعلی، پوشش، تازگی و محدودیت.
- معیار پایان: وضعیت دریافت واقعی هر فیلد ضروری مشخص شود.

### مرحله 3 — اعتبارسنجی مسیرهای عمومی بورس‌ویو (P1)
- کار: اعتبارسنجی ساختار tickers و quotes، شمار رکورد معتبر، کلیدها، واحدها، فیلدهای مفقود و دسترسی؛ بررسی bundle فقط برای یافتن endpoint واقعی.

- معیار پایان: parsing آزموده و بدون ابهام؛ پاسخ ناقص/مسدود باید fail-closed شود.
- وضعیت: کشف مقدماتی قبلی؛ اعتبارسنجی کامل نشده.

### مرحله 4 — بررسی API اختصاصی بورس‌ویو (P1، وابسته به دسترسی)

- معیار پایان: دسترسی واقعی یا تصمیم مستند برای عدم اتکا.

### مرحله 5 — پیاده‌سازی فیلترهای مرجع (P1)

- معیار پایان: تست واحد و نمونه مقایسه مستقل؛ فیلتر بنیادی تا زمان داده معتبر غیرفعال بماند.
- وضعیت: هنوز پیاده‌سازی/تست نشده.

### مرحله 6 — آزمون تاریخی پیش از صف (P2)

## یافته مهم API اختصاصی و تصمیم خرید
اطلاعیه رسمی وب‌سرویس پویا می‌گوید دسترسی‌های API به سه دسته تقسیم شده‌اند:
1. اطلاعات معاملاتی (TSETMC)
2. اطلاعات کدال
3. اطلاعات محاسباتی شامل ضرایب و نسبت‌های مالی

همچنین در اطلاعیه، گزینه‌های دسترسی زمانی به‌صورت «یک ماه پس از خرید»، «یک سال پس از خرید + یک سال تاریخچه» و «یک سال پس از خرید + پنج سال تاریخچه» ذکر شده و گفته شده تعرفه‌ها، راهنمای ورود، endpointها و نمونه‌کد در پنل موجود است.
شاهد رسمی: https://t.me/s/bvhelp?before=160

**ارزیابی خرید:** پیش از خرید باید قیمت و مجوز استفاده، نرخ درخواست، کامل‌بودن endpointها، تأخیر داده و کیفیت تاریخچه بررسی شود. از آنجا که دسته «اطلاعات معاملاتی» مبتنی بر TSETMC معرفی شده، خرید آن صرفاً وقتی ارزش دارد که راحتی integration، پایداری یا تاریخچه بهتر آن از دریافت مستقیم TSETMC مزیت قابل‌اندازه‌گیری داشته باشد. بخش «اطلاعات کدال» و «اطلاعات محاسباتی» احتمالاً ارزش مقایسه بیشتری برای کاهش هزینه استخراج و نرمال‌سازی بنیادی دارد؛ این صرفاً فرضیه تصمیم‌گیری است و باید با قیمت و نمونه داده واقعی سنجیده شود.

**توصیه تصمیم فعلی:** فعلاً خرید انجام نشود. ابتدا API catalog/قیمت و نمونه پاسخ‌ها از پنل رسمی بررسی شود؛ سپس با نمونه محدود و آزمون کیفیت، تصمیم خرید/عدم خرید مستند شود. هیچ endpoint یا قیمت خاصی هنوز تأیید نشده است.
